Write `majority_element(nums)` that returns the value appearing **more than** `len(nums) // 2` times. There's always exactly one.

### Examples

```text
majority_element([3, 2, 3])                    →  3
majority_element([1, 2, 3, 1, 1, 1])           →  1
majority_element([4, 4, 6, 6, 4, 6, 4])        →  4
```
