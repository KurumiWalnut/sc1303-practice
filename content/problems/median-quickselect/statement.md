Write `median(nums)` that returns the **median** of an unsorted list with an **odd** number of values: the middle value once sorted.

### Examples

```text
median([3, 1, 2])            →  2
median([7, 1, 9, 4, 4])      →  4
```

### Constraints

- `1 <= len(nums) <= 200 001`, and the length is odd.
