Write `my_pow(x, n)` that returns xⁿ as a float, **without** `**` or `pow`. `n` can be negative.

Answers within 10⁻⁶ (relative) of the true value are accepted.

### Examples

```text
my_pow(2.0, 10)    →  1024.0
my_pow(2.1, 3)     →  9.261
my_pow(2.0, -2)    →  0.25
```

### Constraints

- `-100 < x < 100`, `-2³¹ <= n <= 2³¹ - 1`, and the answer is between -10⁴ and 10⁴.
