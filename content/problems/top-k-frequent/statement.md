Write `top_k_frequent(nums, k)` that returns the `k` values that appear **most often**, in any order. The answer is always unique.

### Examples

```text
top_k_frequent([1, 1, 1, 2, 2, 3], 2)   →  [1, 2]
top_k_frequent([1], 1)                  →  [1]
```

### Constraints

- Up to 100 000 numbers; `1 <= k <=` the number of distinct values.
