Write `is_anagram(s, t)` that returns `True` if `t` uses exactly the same letters as `s`, the same number of times each, possibly in a different order.

### Examples

```text
is_anagram("anagram", "nagaram")   →  True
is_anagram("rat", "car")           →  False
```

### Constraints

- Up to 100 000 lowercase letters each.
