Write `contains_duplicate(nums)` that returns `True` if any value appears **at least twice**.

### Examples

```text
contains_duplicate([1, 2, 3, 1])                    →  True
contains_duplicate([1, 2, 3, 4])                    →  False
contains_duplicate([1, 1, 1, 3, 3, 4, 3, 2, 4, 2])  →  True
```
