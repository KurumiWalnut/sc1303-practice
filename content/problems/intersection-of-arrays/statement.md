Write `intersection(nums1, nums2)` that returns the values found in **both** lists, each value **once**, in any order.

### Examples

```text
intersection([1, 2, 2, 1], [2, 2])            →  [2]
intersection([4, 9, 5], [9, 4, 9, 8, 4])      →  [9, 4]    (or [4, 9])
intersection([1, 2, 3, 4, 5], [0, 2, 4, 6, 8])  →  [2, 4]
```

### Constraints

- Up to 100 000 values in each list.
