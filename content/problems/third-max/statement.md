Write `third_max(nums)` that returns the **third largest distinct** value in `nums`. If there are fewer than three distinct values, return the **largest**.

### Examples

```text
third_max([3, 2, 1])      →  1
third_max([1, 2])         →  2       (no third distinct value)
third_max([2, 2, 3, 1])   →  1       (distinct values: 3, 2, 1)
```

### Constraints

- Up to 100 000 values.
