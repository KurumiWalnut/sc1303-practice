Write `reverse_list(head)` that reverses a singly linked list **in place** and returns the new head.

Don't create new nodes.

### Examples

```text
1 -> 2 -> 3 -> 4 -> 5   →   5 -> 4 -> 3 -> 2 -> 1
1 -> 2                  →   2 -> 1
(empty)                 →   (empty)
```

### Constraints

- Up to 20 000 nodes, so a recursive solution will hit Python's recursion limit.
