Write `longest_common_prefix(strs)` that returns the longest string that **every** string in `strs` starts with, or `""` if there isn't one.

### Examples

```text
longest_common_prefix(["flower", "flow", "flight"])   →  "fl"
longest_common_prefix(["dog", "racecar", "car"])      →  ""
```

### Constraints

- `1 <= len(strs) <= 1000`
- Each string has at most 1000 lowercase letters (it may be empty).
