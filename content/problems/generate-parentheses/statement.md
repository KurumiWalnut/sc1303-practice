Write `generate_parenthesis(n)` that returns every string of `n` pairs of **well-formed** brackets, in any order.

### Examples

```text
generate_parenthesis(3)  →  ["((()))", "(()())", "(())()", "()(())", "()()()"]   (any order)
generate_parenthesis(1)  →  ["()"]
```

### Constraints

- `1 <= n <= 12`
