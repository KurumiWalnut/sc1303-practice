Write `kth_smallest(nums, k)` that returns the `k`-th smallest value in `nums` (1-based, repeats counted separately), **without** sorting the whole list.

Don't change `nums`.

### Examples

```text
kth_smallest([7, 10, 4, 3, 20, 15], 3)   →  7
kth_smallest([7, 10, 4, 3, 20, 15], 1)   →  3
kth_smallest([2, 1, 2], 3)               →  2
```

### Constraints

- Up to 100 000 values; `1 <= k <= 10`.
