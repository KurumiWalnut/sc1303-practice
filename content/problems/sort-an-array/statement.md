Write `sort_array(nums)` that returns `nums` sorted in ascending order, **without** `sorted()` or `.sort()`. It must run in O(N log N) on every input, including already-sorted lists and lists full of equal values.

### Examples

```text
sort_array([5, 2, 3, 1])           →  [1, 2, 3, 5]
sort_array([5, 1, 1, 2, 0, 0])     →  [0, 0, 1, 1, 2, 5]
```

### Constraints

- Up to 50 000 values between -50 000 and 50 000.
