Write `remove_nth_from_end(head, n)` that removes the **n-th node from the end** of the list and returns the head. `n = 1` means the last node.

### Examples

```text
remove_nth_from_end(1 -> 2 -> 3 -> 4 -> 5, 2)   →   1 -> 2 -> 3 -> 5
remove_nth_from_end(1, 1)                        →   (empty)
remove_nth_from_end(1 -> 2, 1)                   →   1
```

### Constraints

- 1 to 100 000 nodes, and `1 ≤ n ≤` the length of the list.
