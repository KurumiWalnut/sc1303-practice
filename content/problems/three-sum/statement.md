Write `three_sum(nums)` that returns every **distinct** triplet `[a, b, c]` of values from different positions in `nums` with `a + b + c == 0`. Each triplet should appear once; order doesn't matter.

### Examples

```text
three_sum([-1, 0, 1, 2, -1, -4])   →  [[-1, -1, 2], [-1, 0, 1]]
three_sum([0, 1, 1])               →  []
three_sum([0, 0, 0])               →  [[0, 0, 0]]
```

### Constraints

- Up to 1 500 values.
