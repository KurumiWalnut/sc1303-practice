Write `two_sum(nums, target)` that returns the **indexes** of the two numbers that add up to `target`, in any order. There's exactly one answer, and you can't use the same element twice.

### Examples

```text
two_sum([2, 7, 11, 15], 9)   →  [0, 1]
two_sum([3, 2, 4], 6)        →  [1, 2]
two_sum([3, 3], 6)           →  [0, 1]
```

### Constraints

- Up to 100 000 numbers.
