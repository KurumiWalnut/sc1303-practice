Write `sort_array_by_parity(nums)` that returns the numbers with **all the even numbers first**, then all the odd ones. Any order inside each group is fine, so the tests use `check_parity(result, nums)` (see **Provided code**).

### Examples

```text
sort_array_by_parity([3, 1, 2, 4])   →  [2, 4, 3, 1]   (or [4, 2, 1, 3], ...)
sort_array_by_parity([0])            →  [0]
```
