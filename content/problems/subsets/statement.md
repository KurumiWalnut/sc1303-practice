`nums` holds distinct numbers. Write `subsets(nums)` that returns **every** subset (the power set), in any order, each one as a list. It includes the empty list and `nums` itself.

### Examples

```text
subsets([1, 2, 3])   →  [[], [1], [2], [1, 2], [3], [1, 3], [2, 3], [1, 2, 3]]   (any order)
subsets([0])         →  [[], [0]]
```

### Constraints

- `1 <= len(nums) <= 15`
