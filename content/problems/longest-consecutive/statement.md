Write `longest_consecutive(nums)` that returns the length of the longest run of **consecutive whole numbers** (like 4, 5, 6, 7) that can be made from the values in `nums`. The order in `nums` doesn't matter.

### Examples

```text
longest_consecutive([100, 4, 200, 1, 3, 2])           →  4     (1, 2, 3, 4)
longest_consecutive([0, 3, 7, 2, 5, 8, 4, 6, 0, 1])   →  9
longest_consecutive([])                               →  0
```

### Constraints

- Up to 100 000 numbers between -10⁹ and 10⁹.
