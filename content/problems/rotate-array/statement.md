Write `rotate(nums, k)` that rotates `nums` to the **right** by `k` steps, **in place**: each value moves `k` places right, and values falling off the end wrap round to the front.

### Examples

```text
nums = [1, 2, 3, 4, 5, 6, 7];  rotate(nums, 3)   →  [5, 6, 7, 1, 2, 3, 4]
nums = [-1, -100, 3, 99];      rotate(nums, 2)   →  [3, 99, -1, -100]
```

### Constraints

- Up to 100 000 values; `0 <= k <= 10⁹`.
