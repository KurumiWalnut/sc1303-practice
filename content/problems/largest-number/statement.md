Write `largest_number(nums)` that arranges the non-negative integers in `nums` to form the **largest** possible number, returned as a **string**.

The answer has no leading zeros: if every number is 0, return `"0"`.

### Examples

```text
largest_number([10, 2])              →  "210"
largest_number([3, 30, 34, 5, 9])    →  "9534330"
largest_number([0, 0])               →  "0"
```

### Constraints

- Up to 2 000 numbers, each up to 10⁹.
