Every value in `arr2` is distinct and appears in `arr1`. Write `relative_sort_array(arr1, arr2)` that sorts `arr1` so its values come in the **same order as in `arr2`**, with any values not in `arr2` placed at the end in **ascending** order.

### Examples

```text
relative_sort_array([2, 3, 1, 3, 2, 4, 6, 7, 9, 2, 19], [2, 1, 4, 3, 9, 6])
    →  [2, 2, 2, 1, 4, 3, 3, 9, 6, 7, 19]
relative_sort_array([28, 6, 22, 8, 44, 17], [22, 28, 8, 6])
    →  [22, 28, 8, 6, 17, 44]
```
