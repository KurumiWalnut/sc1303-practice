`lists` is a list of `k` lists, each already sorted in ascending order. Write `merge_k_sorted(lists)` that returns one sorted list holding every value.

### Examples

```text
merge_k_sorted([[1, 4, 5], [1, 3, 4], [2, 6]])   →  [1, 1, 2, 3, 4, 4, 5, 6]
merge_k_sorted([])                               →  []
merge_k_sorted([[], [7]])                        →  [7]
```

### Constraints

- Up to 2 000 lists and 100 000 values in total.
