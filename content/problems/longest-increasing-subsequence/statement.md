Write `length_of_lis(nums)` that returns the length of the longest **strictly increasing subsequence**. A subsequence keeps the original order but can skip elements.

### Examples

```text
length_of_lis([10, 9, 2, 5, 3, 7, 101, 18])   →  4     (2, 3, 7, 101)
length_of_lis([0, 1, 0, 3, 2, 3])             →  4
length_of_lis([7, 7, 7, 7])                   →  1
```

### Constraints

- `1 <= len(nums) <= 2500`
