`s` is a **list** of characters. Write `reverse_string(s)` that reverses it **in place** and returns nothing. Don't build a new list.

### Examples

```text
s = ["h", "e", "l", "l", "o"];  reverse_string(s)   →  s is ["o", "l", "l", "e", "h"]
s = ["H", "a", "n", "n", "a", "h"]                  →  ["h", "a", "n", "n", "a", "H"]
```
