`nums` holds only 0s, 1s and 2s (red, white and blue). Write `sort_colors(nums)` that sorts it **in place** so all the 0s come first, then the 1s, then the 2s. It doesn't need to return anything.

Do it in **one pass**, without `sort()`.

### Examples

```text
nums = [2, 0, 2, 1, 1, 0]   →  after sort_colors(nums):  [0, 0, 1, 1, 2, 2]
nums = [2, 0, 1]            →  [0, 1, 2]
```
