Write `remove_element(nums, val)` that removes every `val` from `nums` **in place** and returns `k`, the number of values left. The first `k` positions of `nums` must hold the kept values (in any order); what's after them doesn't matter.

### Examples

```text
nums = [3, 2, 2, 3];  remove_element(nums, 3)               →  2,  nums starts [2, 2]
nums = [0, 1, 2, 2, 3, 0, 4, 2];  remove_element(nums, 2)   →  5,  nums starts [0, 1, 3, 0, 4] (any order)
```
